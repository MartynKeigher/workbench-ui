Splitter

A handle between two panes that resizes one of them. Drag it, or focus it and use the arrow keys, Home and End. Enter or a double-click collapses the pane.

Splitter

It writes the size to --wb-split on its parent, so your layout decides how to use it.

Tabs

A strip of tabs, one per open item, as in a browser. The strip holds no content: you decide what each tab shows.

Tab strip

One tab per open item. Click to select, × to close, drag to reorder, right-click for the menu. Close them all to see the empty message. 

const tabs = new Tabs({
  element: document.getElementById('tabsPlain'),
  onSelect: (id) => tabs.activate(id),
  onClose: (id) => tabs.close(id),
  // Shown when every tab is closed; leave it out to hide the strip instead
  empty: { text: 'No open files.', action: 'Reopen them', onAction: reopen },
});
tabs.open('plan', 'Project plan');
tabs.open('notes', 'Release notes');
tabs.open('q3', 'Q3 report');

With a Home tab

An icon tab that always sits first. It is active when no other tab is.

const tabs = new Tabs({
  element: document.getElementById('tabsHome'),
  onSelect: (id) => tabs.activate(id),
  onClose: (id) => tabs.close(id),
  onHome: () => tabs.activate(null),
});
tabs.setHome(true);
tabs.open('q3', 'Q3 report');
tabs.activate(null);

With a pinned tab

Pinned tabs sit first and have no ×. Pin or unpin from the right-click menu.

const tabs = new Tabs({
  element: document.getElementById('tabsPinned'),
  onSelect: (id) => tabs.activate(id),
  onClose: (id) => tabs.close(id),
});
tabs.open('guide', 'Style guide');
tabs.togglePin('guide');

Dialog

Styles for a native <dialog>. The browser keeps the focus inside, closes it on Escape and hands the focus back.

Confirm

Asks a yes / no question and resolves true or false. With danger, the focus starts on Cancel. 

const yes = await confirmDialog({
  title: 'Delete Q3 report?',
  message: "It goes for everyone with access. This can't be undone.",
  confirmLabel: 'Delete',
  danger: true,
});
